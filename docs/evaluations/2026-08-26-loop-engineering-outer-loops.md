## 수정 이력 요약

- 도입부에 구체적인 실패 장면과 독자·목적·글의 범위를 추가했다.
- 루프·하네스·그래프의 역할과 차이를 다시 정의하고, 각 개념을 실제 실행 구조에 연결했다.
- 상태 계약, 재시작 규칙, 외부효과 승인 경계, 검증 계약을 추가했다.
- 비용·시간 비교의 측정 범위와 해석 한계를 명시했다.
- 개인 시스템의 실행 주기·재시도·쿨다운은 설정에서 확인한 값과 장기 운영 성과를 구분했다.
- 공식 문서와 연구 자료를 주장별로 연결하고, 의역·작성자 해석·종합 해석을 표시했다.
- 사용자가 제시한 AI 느낌 네 가지를 문장 호흡, 문장·문단 경계, 문장 간 흐름, 지시 대상의 자연스러움으로 채점 기준에 반영했다.
